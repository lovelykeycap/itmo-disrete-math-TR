\question
Модули мастерской. Брюс Беннер собирает LEGO-пульт Старка из трёх типов модулей. Их булевы функции заданы векторами:
\[
g(x,y)=(0111),\qquad h(x,y)=(1001),\qquad k(x,y)=(0000).
\]
Модули используются повторно, входы разрешено отождествлять. Внешних константных входов нет.
\begin{enumerate}
\item По критерию Поста найдите все безызбыточные полные подсистемы $\{g,h,k\}$: удаление любой функции из такой подсистемы должно нарушать полноту.
\item Для каждой найденной подсистемы выразите $\neg x$ и $x\land y$ суперпозициями только её функций. Если нужны константы, также получите их из этих функций.
\end{enumerate}
