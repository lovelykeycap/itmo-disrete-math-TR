\question
В коворкинге ИТМО стоит робот-бариста «Арабика-3000». Хакер Лёва разобрал его и обнаружил, что вся логика собрана всего из двух типов чипов: чип «И» реализует импликацию $h_1(x, y) = x \to y$, чип «Ч» — сложение по модулю два $h_2(x, y) = x \oplus y$. Лёва хочет перепрошить робота под любую булеву схему, но сомневается, хватит ли ему этих чипов.

\begin{enumerate}
    \item Проверьте каждый чип по отдельности: является ли $h_1$ или $h_2$ полной системой из одной функции?
    \item Полна ли система $\{h_1, h_2\}$? Ответ обоснуйте по критерию Поста.
    \item Помогите Лёве: соберите из чипов схемы для $\overline{x}$, $x \lor y$ и $x \land y$.
\end{enumerate}
