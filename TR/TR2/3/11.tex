\question
Задана булева функция $F(x,y,z,w)$, которая возвращает истину тогда и только тогда, когда вектор входных значений содержит число единиц из множества $\{0,4\}$.
\begin{enumerate}
\item Постройте таблицу истинности для данной функции.
\item Выразите функцию исключительно через базис ИЛИ-НЕ (стрелка Пирса).
\item Постройте полином Жегалкина методом неопределенных коэффициентов или с помощью треугольника Паскаля.
\item Проверьте, является ли функция самодвойственной.
\end{enumerate}
